# Contributing

## Corrections

Corrections to published labs are welcome. Open an issue or a pull request naming the workshop and the lab. Broken commands, stale console paths, and moved dataset links are all worth reporting.

## New labs

Talk to us before writing one. A lab that fits no existing workshop track will not be merged.

An accepted lab must:

- apply the tagging standard in [`docs/delivery.md`](docs/delivery.md)
- ship with its own dataset, or a script that fetches one
- state its prerequisites and the permissions it needs

Labs assume infrastructure is provisioned in advance. Anything requiring live provisioning is a demo, not a lab.

## Student submissions

Work goes in `workshops/<workshop>/projects/submission/<name>/`. Do not edit shared files. Do not commit credentials.
