# Naeem Saleem — Notice Board Feature

This folder contains my isolated feature submission for the Notice Board project.
It adapts the team bank application's React/Vite frontend into a focused notice
board where users can:

- post a notice with their name and a message;
- see newest notices first;
- delete notices; and
- keep notices between browser refreshes with `localStorage`.

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Open the local URL printed by Vite.

## Validate

```bash
cd frontend
npm run build
```

No credentials or environment files are required for this frontend feature.
