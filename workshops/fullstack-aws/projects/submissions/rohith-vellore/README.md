# Welcome Page Feature

## Description

This submission adds a simple interactive welcome page to the Full Stack AWS workshop.

The page provides a welcoming introduction for users visiting the workshop and includes an interactive button that displays additional information.

## Features

- Responsive welcome page design
- Blue background with an orange action button
- Interactive **Explore Workshop** button
- JavaScript functionality to show and hide a welcome message
- Separate HTML, CSS, and JavaScript files

## Files

- `welcome-page/index.html` - Structure of the welcome page
- `welcome-page/style.css` - Styling and layout
- `welcome-page/script.js` - Button interaction

## How to Run

Open `welcome-page/index.html` in a web browser.
